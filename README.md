# EduMapJourney_Protfolio

This repository contains the coursework protfolio website for **EduMapJourney**.
and this is the demo github link:https://github.com/danyih05/edujour

## How to View

Clone the repository and open `index.html` in your browser:

```bash
git clone <repository-url>
cd EduJourney_Portfolio
open index.html   # macOS
# or
start index.html  # Windows
# or
xdg-open index.html # Linux
```

## Portfolio Contents

- Journey RPG
- Live Program
- Try the Real System
- Open the live Journey RPG experience
- Project Timeline
- Motivation & Research
- User Requirements
- Ideation & Alternatives
- Technical Implementation
